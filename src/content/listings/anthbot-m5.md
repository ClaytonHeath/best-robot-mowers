## What it is

Anthbot **M5** is the **$649** base wire-free SKU on the official US M5 PDP (Shopify Package option **M5**, SKU **105010082**, variant id **51871722078510**). It is cart-live on 11 Sep 2026. Navigation is **Full-Band RTK + Dual Vision** (two HDR / 150° wide-angle cameras) with **built-in 4G** and no perimeter wire. This is the **M5 / Mowie product line**, not a Genie variant — do not confuse it with the already-listed **Genie 600e (4G)**, **Genie 1000**, or **Genie 3000**. The same M5 PDP also sells accessory bundles; this listing locks the **base M5** cart line only (not M5 + Garage, not M5 + Blades + RTK Wall Mount Kit, and not **M5 LiDAR** or **M9**).

## Who it's for

Small urban and suburban lawns near Anthbot’s published **up to 500 m²** design footprint (≈ **0.12 acre**) where the owner wants a **10-minute wire-free** RTK setup, app cutting-height control, on-edge mowing in a compact chassis that fits narrow passages, and **4G** for remote app control / Network RTK. Official slope callout on the PDP is **24° / 45%**. Wrong machine if the measured yard is past **500 m²**, if you need the larger **M9** (1000 m² class on Anthbot’s related PDPs), if you specifically want the **M5 LiDAR** sibling, or if you actually need a listed **Genie** SKU.

## Standout details

- **Price:** Official US cart accepted base **M5** at **$649.00** (compare-at **$799.00**) on 11 Sep 2026; parent PDP `product:price:amount` is **649.00** USD — do not use bundle row prices ($679).
- **Coverage:** PDP copy and model comparison both state **up to 500 m²** / **500㎡ | Full-Band RTK + Dual Vision | 4G** for M5 ≈ **0.12 acre** — used for `coverageAcres`. No separate higher marketed acre ceiling is published on this PDP the way Genie SKUs split recommended vs. variant label.
- **Navigation:** **Full-Band RTK + Dual Vision**; visual odometry when satellites are obstructed; AI obstacle detection (PDP: 1,000+). Wire-free. **Network RTK** via built-in 4G is described as included at no extra cost; optional physical RTK station / NetRTK accessory paths are also marketed on the same page.
- **4G / app:** Built-in 4G for remote app control, GPS tracking, and security alerts; app multi-zone scheduling cited for **20 zones**; OTA updates; rain sensor auto-home.
- **Slope / cut:** **24° / 45%** slope; cutting width **20 cm (7.9 in)** 5-blade disc; height **3–7 cm** app-adjusted; marketing efficiency **150 m²/h**.
- **Build (published on PDP):** Noise **≤ 58 dB** (standard mode); waterproof **IPX6**.
- **In the box (PDP “Whats in the box”):** M5, charging station, tool kit, one set of blades, plus RTK reference station / mounting pole / tripod fixing stake / RTK power extension cable as listed on the packaging section.

## Honest verdict

M5 is the compact live-cart Anthbot for a **published up-to-500 m² (~0.12 acre)** wire-free yard with **RTK + dual vision**, **4G**, a **7.9 in** disc, and a **45%** slope limit at **$649**. Buy it for small, tight yards and the base SKU price — not for Genie-class acreage, not as a Genie substitute, and not if you mix in the garage/accessory bundle rows or the **M5 LiDAR** / **M9** siblings.
