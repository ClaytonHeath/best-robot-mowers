## Who it's for

This fits a lawn whose **mowable area is within about 0.37 acre**, where you want virtual boundaries instead of buried wire, and where RTK plus onboard vision is enough without stepping into a larger AWD chassis. RoboUP's page says you can map automatically or manually in the app, create unlimited zones and no-go areas, and run edge passes after the main cut.

Plan the install before you buy. There is **no perimeter wire**, but the system still uses an **RTK** reference setup and a **charging station**. The same US PDP sells an optional RTK mount rod as a separate variant; this listing is the mower-only SKU.

Skip it if the grass area is past about 0.37 acre, if you need a published AWD rating or a slope at the 70%+ class, or if you want a wider deck that finishes a big lawn in fewer passes. The published maximum on this page is **45%** inside the work area.

## Honest verdict

At **$799** on sale from **$1,549**, the TM01 T1200Pro is RoboUP's mid-small wire-free RTK+vision mower for yards up to **0.37 acre**: no perimeter wire, a **7.87-inch** cut, **1.2–2.4 in** electric height, **IPX6**, and a published **45%** max slope.
