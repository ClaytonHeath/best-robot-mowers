## What it is

Husqvarna Automower 410 iQ is a residential, EPOS satellite-mapped robot mower. The US/CA SKU is **970 72 74-01**. Husqvarna leads with **0.5 acre lawn size (±20%)** — the same figure as **area capacity — systematic**. **Area capacity — irregular** is **0.25 acre**. Boundary type is **Physical wire, Virtual wire**. A normal install does not require buried loop wire.

The box includes the mower, charging station, 6 extra blades, 33 ft low-voltage cable, power supply, 100 stakes, EPOS Plug-in, and EPOS Reference station. **Loop wire is not included.** husqvarna.com lists it at **$2,599.99** and its official cart returned that price on 20 Oct 2026.

## Who it's for

Suburban lawns around **half an acre** when mowed systematically — **a quarter acre if the layout is irregular** — that will use EPOS virtual mapping instead of buried wire. Official slope is **45% inside the work area** and **15% at the boundary**. It is the wrong machine if the grass is over about half an acre, if the layout is a messy quarter-acre-plus, or if you need all-wheel drive (that is a different SKU).

## Honest verdict

This is the small-yard iQ Automower for a **systematic ~0.5-acre** lawn: EPOS virtual mapping, 9.4 in deck, IPX5, no buried wire required. The catch is capacity and terrain — Husqvarna itself rates **irregular layouts at 0.25 acre**, in-lawn slope at **45%** (15% at the boundary), and the install still includes an **EPOS reference station**. It is not the 440 iQ, the 435X AWD, or the 435 iQ AWD.
