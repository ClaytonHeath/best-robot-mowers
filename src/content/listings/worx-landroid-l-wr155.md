## What it is

Worx Landroid L WR155 is a **boundary-wire** robot mower for lawns up to **½ acre (21,780 sq ft)**. It is not the Vision Cloud line: no cameras, no RTK Cloud, no virtual map. A buried (or pegged) loop defines the work area. Worx’s AIA turning is for narrow passages *inside* that loop — the page says it can go through gaps as narrow as the mower without a separate guide wire.

The US box includes the mower, a **5.0 Ah** PowerShare battery (WA3671), charging station (WA0464), **820 ft of boundary wire**, **340 pegs**, connectors, blades, and hardware. Official cart on 28 Aug 2026 was **$699.99** for this SKU, **temporarily out of stock**.

## Who it's for

Flat-to-moderate suburban lawns around **half an acre** where the owner will install perimeter wire (or pay someone to) and already owns, or wants, Worx 20V PowerShare tools. Official maximum slope is **30%**. Wrong machine if you will not bury wire, if the grass is actually over half an acre once you measure, or if you wanted the wire-free Vision Cloud WR310.

## Honest verdict

This is the wire-era Landroid for a measured **half-acre**: PowerShare battery, pegs and 820 ft of wire in the box, no RTK pole and no cameras. The catch is the install and the limits in the spec table — **30% slope**, **8 in** of blade, **manual** height, and you have to bury that loop. If you want wire-free vision, that is WR310 (already listed), not this SKU.
