## What it is

Husqvarna Automower 435 iQ AWD is a residential, all-wheel-drive, EPOS satellite-mapped robot mower. The US/CA SKU is **970 74 52-05** (AM435iQAWD US, CA). Husqvarna leads with **1.3 acre Lawn Size (±20%)** — the same figure as **area capacity — systematic**. **Area capacity — irregular** is **0.9 acre**. Boundary type is **Virtual wire, Physical wire**. A normal install does not require buried loop wire.

The box includes the mower, charging station, 6 extra blades, 33 ft low-voltage cable, power supply, and EPOS Reference station. US dealer carts on 1 Sep 2026 ranged **$4,599.99–$4,999.99**. husqvarna.com has no visible cart.

This is not the Automower **435X AWD** (physical-wire AWD, already listed), not the **410 iQ** (970 72 74-01), and not the **440 iQ** (970 72 76-01).

## Who it's for

Yards around **1.3 acres** when mowed systematically — **0.9 acre if the layout is irregular** — that need **AWD** on slopes Husqvarna rates **70% inside the work area** and **50% at the boundary**, and that will use EPOS virtual mapping instead of buried wire. It is the wrong machine if the grass is over about 1.3 acres systematic / 0.9 acre irregular, if you only need a smaller 2WD iQ, or if you specifically want the older physical-wire 435X AWD.

## Honest verdict

This is the steep-yard iQ Automower for a **systematic ~1.3-acre** lawn: EPOS virtual mapping, AWD, 8.7 in deck. The catch is capacity, weather sealing, and install hardware — Husqvarna itself rates **irregular layouts at 0.9 acre**, in-lawn slope at **70%** (50% at the boundary), **IPX4** (not a hose-wash underside), and the kit still includes an **EPOS reference station**. It is not the 435X AWD, the 410 iQ, or the 440 iQ.
